🚀 Full-Stack Developer | AI-Focused Backend Engineer | Building Scalable Systems

I'm a Computer Science graduate pursuing a part-time Master's in Business, building production-grade full-stack and AI-powered applications. I specialize in designing scalable RESTful APIs and clean, modular backend architectures using **Python (FastAPI)** and **TypeScript (NestJS)**, paired with modern frontends in **React** and **Next.js**.

## 🚀 Featured Projects

### 🧠 [Recall — AI Meeting Intelligence](https://github.com/Sehrabdar/Recall)
Full-stack AI-powered meeting intelligence platform. FastAPI + SQLAlchemy 2.0 (async) backend with Next.js/TypeScript frontend. Semantic search via Qdrant vector DB, local LLM inference via Ollama, Redis caching, Celery background workers. Built on Clean Architecture with repository/provider patterns.
`Python` `FastAPI` `PostgreSQL` `Redis` `Qdrant` `Ollama` `Next.js` `TypeScript`

### 🍽️ [BrisketLovers — Restaurant Management System](https://github.com/Sehrabdar/BrisketLovers)
Restaurant management system with automated real-time inventory deduction. Custom `StockDeductionService` calculates ingredient usage per order via TypeORM, paired with an `AvailabilityService` that dynamically syncs menu availability with remaining stock.
`TypeScript` `NestJS` `TypeORM` `PostgreSQL`

### 🔍 [Page Pulse — URL Audit Service](https://github.com/Sehrabdar/PagePulse)
Production-grade URL audit API returning structured reachability, timing, header, and security reports. Async HTTPX requests, Pydantic v2 validation, TTL caching, per-client rate limiting, and concurrency controls.
`Python` `FastAPI` `HTTPX` `Pydantic v2`

### 🎬 [YouTube API — Video Search App](https://github.com/Sehrabdar/Youtube-Api)
Full-stack YouTube search app with a NestJS backend acting as a secure API proxy (API key never exposed to client). React 19 + Vite frontend with client-side routing, DTO-validated endpoints, and full Jest test coverage.
`TypeScript` `NestJS` `React` `Vite` `YouTube Data API v3`
